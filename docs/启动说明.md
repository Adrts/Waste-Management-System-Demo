# 启动说明

> 海口市垃圾全生命周期管理系统 DEMO · 面向演示与验收人员的启动指引
> 技术栈：SQLite + Python FastAPI（后端）· Vue3 + Element Plus + ECharts（前端）

---

## 一、环境要求

| 依赖 | 要求 | 用途 |
|---|---|---|
| Python | ≥ 3.12（开发机为 3.14） | 后端服务、模拟数据生成 |
| Node.js / npm | ≥ 18 / ≥ 9 | 仅前端**开发或重新构建**时需要（演示可直接用已构建产物） |
| 浏览器 | 桌面版 Chrome / Edge | 展板与管理页均按桌面浏览器设计 |

> 首次部署新机器时：Python 依赖装进项目根 `.venv`（虚拟环境，不污染系统），
> Node 依赖装在 `src/web/node_modules`。

---

## 二、首次部署（新机器执行一次）

```powershell
# 1. 创建 Python 虚拟环境并安装后端依赖
cd ###工程根目录###
python -m venv .venv
.venv\Scripts\python -m pip install -r src\server\requirements.txt

# 2. 安装前端依赖（仅开发/重建时需要）
cd src\web
npm install

# 3. 生成模拟数据库（若 src\server\data\wms.db 已存在可跳过）
cd ..\server\app
..\..\..\.venv\Scripts\python generator.py     # 建 6 表 + 26 万行缩比模拟数据
..\..\..\.venv\Scripts\python validate.py      # 数据自检（对照验收 D-1~D-8，应 30/30 通过）
```

## 三、日常启动

### 方式一：一键启动（推荐）

双击项目根目录的 **`启动.bat`**。脚本会按顺序自动完成 5 步检查，全部通过后启动服务并自动打开展板：

1. 检测 Python 是否存在、pip 是否可用；
2. 检测 Node.js / npm 是否可用（缺失仅告警，不影响演示）；
3. 检查 Python 依赖（fastapi/uvicorn），缺失则自动创建 `.venv` 并安装 requirements.txt；
4. 检查 npm 依赖与前端构建产物 dist，缺失则自动 npm install / npm run build；
5. 检查数据库 wms.db（缺失自动生成模拟数据），随后启动服务 http://127.0.0.1:8000。

任一步失败会给出原因并指引参照本说明处理。

### 方式二：命令行启动

```powershell
cd d:\Workspace\Waste-Management-System-Demo\src\server
..\..\.venv\Scripts\python run.py 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即启动成功。**前端产物已由后端托管，无需另起前端服务。**

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 端口 8000 被占用 | `python run.py 8001` 换端口；浏览器地址同步改 |
| 页面报"未登录或会话已过期" | 后端重启会清空内存会话，重新登录即可 |
| 想重置全部演示数据 | 停服务 → `cd src\server\app` → `python generator.py`（随机种子固定，可复现） |
| 核对数据指标 | `cd src\server\app` → `python validate.py`，输出 D-1~D-8 共 30 项自检结果 |
| 模拟规律在哪 | `src\server\data\meta.json`：春节/台风/周末规律参数与全部注入异常样本清单 |
| 换了电脑跑不起来 | 按"首次部署"四步重来；`.venv` 与 `node_modules` 不随仓库分发 |
